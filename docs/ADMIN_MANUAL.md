# HearBridge AI Administrator Manual

This guide describes how to operate the administrative portals of HearBridge AI.

## 1. Super Admin Dashboard

The Super Admin controls global platform variables, organizations, billing, and system configurations.

### Key Sections:
- **Global Overview**: Track active organizations, therapist/patient counts, monthly recurring revenue (MRR), and system resource usage.
- **Tenant Management**: Onboard new clinics, edit user permissions, or suspend subdomains.
- **Dynamic Localization**: Edit translation tables in real time. Translations update instantly in the database, requiring no mobile/web code changes.
- **Buyer Transfer Panel**: Facilitates turnkey corporate acquisitions. Hand over Stripe secrets, SMTP relays, custom domains, and administrator access in 1 click.

---

## 2. Organization/Clinic Admin Dashboard

The Clinic Admin handles clinic-level configurations, billing plans, therapist assignments, and branding.

### Key Sections:
- **Branding Customizer**: Adjust primary colors, app titles, logo URLs, and email SMTP configurations for the clinic's portal.
- **Therapist Onboarding**: Add therapists and assign patients to their rosters.
- **Usage Metrics**: Audit active workouts and generate progress reports for insurance providers.
